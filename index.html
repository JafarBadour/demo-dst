What is Dynamic Sparse Training?

  • Start with a network where only a fraction of weights are active.
  • Train only active weights, while inactive edges stay at zero.
  • Periodically remove weak edges and grow new promising edges.
  • Goal: near-dense performance with much lower active parameter count.
Demo behavior is intentionally small/fast for live presentations.
