Dynamic Sparse Training

An interactive look at how sparse neural networks rewire themselves to recover dense-level behavior with far fewer active parameters.

01Can sparse networks learn dense-level behavior?

This article introduces the dynamic sparsity setup we use in our research and pairs the explanation with a live, in-page training demo. As the model trains, you can watch its connectivity reshape in real time and see compute and memory savings update with it.

The underlying question is simple: how much of a dense network do we actually need? Dynamic sparse training answers this empirically. We keep only a fraction of the weights active and let the network discover which ones matter as training proceeds.

02Before you run the demo

We start with a network where only a fraction of weights are active. During training, only those active weights receive updates; inactive edges stay at zero. Periodically the network performs a rewiring step: it removes weak edges and grows new promising ones, so the training compute concentrates on the most useful subnetwork.

The model used in the demo is intentionally tiny so that an entire training run finishes in a few seconds — small enough to demo live, large enough to show the dynamics clearly.

03How to read the visualization

The connectivity view animates each forward and backward pass: blue pulses mark feedforward, pink pulses mark backprop, and yellow highlights mark the rewiring epochs where weak edges are pruned and new candidate edges are grown.

The metrics panel tracks task loss and accuracy over time. Live FLOPs and memory counters compare what the sparse model touches against what a dense model would have touched, exposing the efficiency trade-off in real time.

Try increasing sparsity, switching the rewiring strategy, or editing the architecture under the gear icon. Watch how each choice changes recovery speed and the savings relative to dense training.

04Where this research goes next

The toy demo above is deliberately small, but the rewiring logic generalizes. Our follow-up work pursues three threads.

Scaling beyond toy tasks

We apply the same rewiring logic to deeper models and larger datasets to measure stability, convergence speed, and final quality under strict compute budgets.

Adaptive rewiring schedules

Instead of a fixed interval, we are testing trigger-based rewiring tied to gradient saturation and plateau detection so that updates land where they matter most.

Hardware-aware sparse training

We are also investigating kernels and placement strategies that turn theoretical sparse savings into measured wall-clock gains on modern accelerators.

Can dynamic sparsity be both scientifically competitive and operationally efficient at real deployment scale?
